Política de privacidade

Vigente desde 15 de novembro de 2026. Aplica-se ao Tronqueira Publicador, ferramenta interna do canal Histórias da Tronqueira.

Quem usa

Só o dono do canal, na própria conta Google. Não há outros usuários.

Dados do Google que a ferramenta acessa

  • YouTube Data API: enviar vídeos, miniaturas e legendas ao próprio canal e listar os vídeos dele.
  • YouTube Analytics API: ler métricas agregadas do próprio canal (visualizações, tempo de exibição, inscritos).

Como os dados são usados e guardados

As métricas servem apenas para o relatório interno do canal. As credenciais de acesso ficam guardadas como segredos criptografados no repositório privado da ferramenta. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O uso das APIs do YouTube segue os Termos de Serviço do YouTube (https://www.youtube.com/t/terms) e a Política de Privacidade do Google (https://policies.google.com/privacy).

Como revogar

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions. Os dados guardados são apagados quando o acesso é revogado.
