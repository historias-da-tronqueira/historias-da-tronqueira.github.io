Política de privacidade

Vigente desde 15 de novembro de 2026. Aplica-se ao Tronqueira Publicador, ferramenta interna do canal Histórias da Tronqueira.

Uso dos Serviços de API do YouTube

O Tronqueira Publicador usa os Serviços de API do YouTube. Ao usá-lo, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados também segue a Política de Privacidade do Google.

Quem usa

Só o dono do canal, na própria conta Google. Não há outros usuários.

Dados acessados

  • YouTube Data API: enviar vídeos, miniaturas e legendas ao próprio canal e listar e atualizar os vídeos dele.
  • YouTube Analytics API: ler métricas agregadas do próprio canal (visualizações, tempo de exibição, inscritos).

Como os dados são usados, guardados e compartilhados

As métricas servem apenas para o relatório interno do canal. O token de acesso fica guardado como segredo criptografado no repositório privado da ferramenta; as métricas agregadas ficam no mesmo repositório privado. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos. Não são usados cookies nem rastreamento.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento na página de permissões de segurança do Google. Depois da revogação, o token e os dados obtidos pela API são apagados em até 30 dias. A exclusão também pode ser pedida pelo e-mail historiasdatronqueira@gmail.com.
